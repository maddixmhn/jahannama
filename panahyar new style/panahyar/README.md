# پناه‌یار — Panahyar.online

دانشنامه و سامانه تخصصی پناهندگی ایرانیان. ساخته‌شده با **PHP خالص (بدون فریمورک)** + **MySQL/MariaDB**.

---

## ۱. امکانات

- صفحه اصلی با **نقشه تعاملی کشورها** به تفکیک قاره + مودال شرایط پناهندگی هر کشور
- **پارالاکس موشن** در پس‌زمینه + **منوی ثابت پایین** فقط در موبایل
- **ماشین‌حساب مهاجرت** کاملاً سمت کلاینت (بدون ذخیره هیچ داده‌ای) با بخش خانواده (همسر، فرزندان، والدین، خواهر/برادر)
- **فرم درخواست مشاوره** با کد پیگیری ۶ رقمی + آپلود امن مدارک + جلوگیری از ارسال تکراری ۲۴ ساعته
- **صفحه پیگیری** برای مشتری بدون ثبت‌نام (با شماره واتساپ + کد)
- **پنل مدیریت** کامل: درخواست‌ها، پیام به مشتری، گواهی‌ها، وکلا، اخبار، قوانین، تعرفه، صفحه درباره ما
- **ماشین‌حساب تعرفه** فعال با تخفیف‌ها — هماهنگی پرداخت از طریق واتساپ
- بخش اخبار با درج منبع، بخش قوانین، بخش گواهی‌ها
- **محافظت ضد کپی** (راست‌کلیک، کپی، چاپ، کشیدن، کلیدهای میانبر)
- امنیت: جلوگیری از SQL Injection (PDO prepared)، XSS (escape خروجی)، CSRF (توکن همه فرم‌ها)، session امن، هدرهای امنیتی + CSP

---

## ۲. پیش‌نیازها

- PHP **8.1+** با افزونه‌های: `pdo_mysql`, `mbstring`, `fileinfo`
- MySQL **8.0+** یا MariaDB **10.6+**
- وب‌سرور Apache (با `mod_rewrite`, `mod_headers`) یا Nginx
- گواهی **SSL** (مثلاً Let's Encrypt) — اجباری

---

## ۳. ساختار فایل‌ها

```
panahyar/
├── config/
│   ├── config.php        ← تنظیمات پایه + خواندن اعتبارنامه از متغیر محیطی
│   ├── database.php      ← اتصال PDO (prepared statements)
│   └── contact.php       ← شماره واتساپ، اینستاگرام، جمله تخصص
├── includes/
│   ├── security.php      ← escape (XSS)، CSRF، session امن، هدرها
│   ├── auth.php          ← ورود/خروج/نگهبان مدیر
│   ├── upload.php        ← آپلود امن با بررسی MIME واقعی
│   ├── header.php        ← هدر مشترک صفحات عمومی + نوار اعلان
│   └── footer.php        ← فوتر + منوی موبایل + واتساپ شناور
├── public/               ← ★ DocumentRoot را روی این پوشه بگذارید
│   ├── index.php         ← صفحه اصلی + نقشه کشورها
│   ├── calculator.php    ← ماشین‌حساب مهاجرت
│   ├── consult.php       ← فرم مشاوره + آپلود مدارک
│   ├── track.php         ← پیگیری درخواست
│   ├── laws.php          ← قوانین
│   ├── news.php          ← اخبار
│   ├── certificates.php  ← گواهی‌ها + آپلود کاربر
│   ├── about.php         ← درباره کامیار دادبین + وکلا
│   ├── pricing.php       ← تعرفه + ماشین‌حساب هزینه (هماهنگی واتساپ)
│   ├── assets/css/       ← style.css (سایت) + admin.css (پنل)
│   ├── assets/js/        ← main.js + calculator.js
│   └── admin/            ← پنل مدیریت (login, index, consultations, …)
├── uploads/              ← مدارک کاربران (خارج از دسترس عمومی، با .htaccess)
├── sql/
│   ├── schema.sql        ← ساختار جداول + داده اولیه
│   └── seed_countries.sql← فهرست کشورها
└── .htaccess             ← ریدایرکت به public + مسدودسازی پوشه‌های حساس
```

## ۴. نصب گام‌به‌گام

### ۴.۱ ساخت دیتابیس
```bash
mysql -u root -p < sql/schema.sql
mysql -u root -p < sql/seed_countries.sql
```

### ۴.۲ تنظیم اعتبارنامه (متغیر محیطی — هرگز داخل کد ننویسید)
در Apache (فایل `.htaccess` یا کانفیگ سایت) یا محیط سیستم:
```
SetEnv PY_DB_HOST   127.0.0.1
SetEnv PY_DB_NAME   panahyar
SetEnv PY_DB_USER   panahyar_user
SetEnv PY_DB_PASS   «رمز_قوی»
SetEnv PY_ENV       prod
```
> در حالت توسعه `PY_ENV=dev` خطاها را نمایش می‌دهد. در تولید حتماً `prod`.

### ۴.۳ تنظیم DocumentRoot
DocumentRoot وب‌سرور را روی پوشه `public/` بگذارید. اگر روی هاست اشتراکی امکان ندارد، فایل `.htaccess` ریشه به‌صورت خودکار ترافیک را به `public/` هدایت می‌کند.

### ۴.۴ ساخت مدیر اولیه
```bash
PY_DB_HOST=127.0.0.1 PY_DB_NAME=panahyar PY_DB_USER=panahyar_user PY_DB_PASS=رمز \
  php public/admin/create_admin.php <نام‌کاربری> "<رمز_۸+کاراکتر>" "کامیار دادبین"
```
**پس از ساخت، فایل `create_admin.php` را حذف کنید.**

ورود به پنل از آدرس `https://panahyar.online/admin/login` انجام می‌شود.

> **نکته URL:** سایت بدون پسوند `.php` کار می‌کند (مثلاً `panahyar.online/pricing` به‌جای `pricing.php`). فایل `.htaccess` این نگاشت را انجام می‌دهد و اگر کسی `.php` تایپ کند به نسخه تمیز ریدایرکت (۳۰۱) می‌شود. برای این کار به `mod_rewrite` آپاچی نیاز است.

### ۴.۵ دسترسی پوشه آپلود
```bash
chmod 755 uploads
# اطمینان از وجود uploads/.htaccess (مسدودسازی اجرای اسکریپت)
```

## ۵. اخبار و محتوای حقوقی

طبق تصمیم پروژه، محتوای حقوقی و اخبار از طریق **پنل با بازبینی انسانی** و **لینک به منابع رسمی** مدیریت می‌شوند (به‌جای اسکرپ خودکار که از نظر حقوقی و فنی پرریسک است). منابع پیشنهادی اخبار: رادیو فردا، دویچه‌وله فارسی، بی‌بی‌سی فارسی، یورونیوز فارسی. منابع حقوقی: UNHCR، EUAA، سایت‌های دولتی هر کشور.

---

## ۶. نکات امنیتی مهم

- تمام کوئری‌ها از **PDO prepared statements** استفاده می‌کنند (ضد SQL Injection).
- تمام خروجی‌های کاربر با تابع `e()` فرار داده می‌شوند (ضد XSS).
- همه فرم‌ها **توکن CSRF** دارند.
- مدارک کاربران در `uploads/` خارج از دسترس عمومی ذخیره و فقط از طریق `admin/download.php` با احراز هویت سرو می‌شوند.
- IP کاربران **هش** می‌شود، نه ذخیره خام.
- ماشین‌حساب مهاجرت **هیچ داده‌ای** ذخیره نمی‌کند (کاملاً در مرورگر).

> **یادآوری:** محافظت ضد کپی صرفاً بازدارنده است و کاربر حرفه‌ای می‌تواند آن را دور بزند؛ این یک محدودیت ذاتی همه وب‌سایت‌هاست.

## ۷. سلب مسئولیت حقوقی

محتوای سایت جنبه اطلاع‌رسانی دارد و جایگزین مشاوره حقوقی رسمی نیست. ارائه مشاوره پناهندگی در برخی کشورها نیازمند مجوز است؛ از تطابق فعالیت با قوانین محل خود اطمینان حاصل کنید.
